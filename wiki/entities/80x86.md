# Intel 80x86 (x86) Architecture

The **80x86** (or x86) is the CISC microprocessor family Randall Hyde's *The Art of
Assembly Language* teaches — spanning the 8088/8086 through the 80286, 80386, and
80486. The IBM PC is built around this architecture, operating on **binary logic**
(two voltage levels mapped to 0 and 1). See [AoA Ch3: System Organization](/concepts/art_of_assembly/aoa-ch03-system-organization.md).

## Key characteristics (per AoA)

- Uses the **binary numbering system** internally; programmers use hexadecimal as shorthand.
- General-purpose and segment registers; memory addressed via segment:offset (real mode).
- Instruction set covered in [AoA Ch6](/concepts/art_of_assembly/aoa-ch06-the-80x86-instruction-set.md).
- Memory organization detailed in [AoA Ch4](/concepts/art_of_assembly/aoa-ch04-memory-layout-and-access.md).
